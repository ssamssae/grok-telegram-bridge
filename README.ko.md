# Grok Telegram Bridge

[English](README.md) · [한국어](README.ko.md) · [Web guide · 웹 설명서](https://product.kangdaejong.com/grok-telegram-bridge/) · [Web verification](docs/feature-map.md)

텔레그램의 본인 전용 봇으로 컴퓨터의 Grok에 메시지를 보내고 답변을 받습니다.
브릿지 언어는 한국어·영어 중 고를 수 있습니다. AI 답변의 언어와 모델 설정은 별개입니다.

## 0.6.8 변경 사항

`python3 bridge_setup.py setup` 명령 하나로 제작자와 같은 설정을 설치합니다.
TUI 레인과 터미널 턴 폰 미러, 상시 서비스, `grok-tg` 붙기 명령, 두 방향 자가 점검까지 합니다.
[제작자와 똑같이 쓰기](#제작자와-똑같이-쓰기-명령-하나)를 참고하세요.
터미널에서 시작한 턴의 폰 진행 카드에도 중지 버튼이 붙습니다.
브릿지 자체 로컬 입력에 친 글이 오류로 멈추지 않고 다시 Grok에 들어갑니다.
tmux 세션을 다시 띄우면 저장된 Grok 대화를 다시 이어서 엽니다.
[릴리스 안내](RELEASE_NOTES-0.6.8.md)를 참고하세요.

## 0.6.7 변경 사항

답을 기다리는 `/model` 카드를 개인 대화에 고정합니다. 선택·만료·브릿지 재시작 때
해제합니다(`GRB_QUESTION_PIN=0`이면 끕니다). 진행 카드에 중지 버튼이 생겼고
(`GRB_STOP_BUTTON=0`이면 숨깁니다), 사람이 멈춘 턴은 중단으로 닫히며, 진행 카드와
최종 답변은 질문 메시지에 답장으로 달립니다.
[릴리스 안내](RELEASE_NOTES-0.6.7.md)를 참고하세요.

## 즉시입력

Grok이 답을 쓰는 중에 메시지를 보내면 브릿지가 그 메시지를 대기열에 넣고
**즉시입력** 버튼을 보냅니다. 버튼을 누르면 대기 중인 메시지가 현재 턴에
들어갑니다. 입력칸이 비어 있고 화면에 대기열 안내가 있을 때만 Enter를 보냅니다.
Ctrl+C와 Escape는 보내지 않습니다. `GRB_SEND_NOW_BUTTON=0`이면 문장만 보내고
버튼을 숨깁니다. 확인 순서는 [웹 검증](docs/feature-map.md)에 있습니다.

## 0.6.2 변경 사항

같은 작업 폴더에서 여러 Grok 세션을 실행해도 연결된 세션의 답변만 받습니다.
다른 세션의 답변이 현재 요청을 완료 처리하던 문제를 수정했습니다.
입력 중 표시는 현재 요청의 답변이 올 때까지 유지합니다.
세션 변경 후 답변을 복구할 때 질문 전체를 대조합니다.

업데이트 방법은 [0.6.2 릴리스 노트](RELEASE_NOTES-0.6.2.md)를 확인하세요.

## 시작하기

```bash
git clone https://github.com/ssamssae/grok-telegram-bridge.git
cd grok-telegram-bridge
cp config.example.env .env
```

BotFather에서 본인 전용 봇을 만들고, 안내받은 토큰을 로컬 토큰 파일에 저장하세요.
파일 형식은 `{"api_key": "본인 봇 토큰"}`입니다. 이 파일과 `.env`는 공개 저장소나 채팅에 올리지 마세요.
토큰 파일 경로와 본인 채팅 ID를 `.env`의 `GRB_TOKEN_FILE`, `GRB_CHAT_ID`에 지정합니다.
본인 채팅 ID 확인 절차는 [영문 설치 안내](README.md)를 참고하세요.

```bash
set -a
source .env
set +a
python3 grok_telegram_bridge.py
```

`Grok` CLI 설치·로그인과 기존 터미널 세션 연결은 [영문 설치 안내](README.md)를 따릅니다.
공개 실행 파일과 같은 폴더의 공통 Python 파일들도 함께 설치해야 합니다.

### 제작자와 똑같이 쓰기 (명령 하나)

위 수동 절차 대신 명령 하나로 설치할 수 있습니다. BotFather에서 봇을 만들고 저장소를 내려받은 뒤, 내려받은 폴더에서 실행합니다.

```bash
python3 bridge_setup.py setup --language ko
```

첫 질문 `Use the author's setup (recommended)? [Y/n]`에서 Enter를 누르면 제작자 설정을 씁니다.
사람 손이 필요한 일은 둘뿐입니다. 숨김 입력칸에 봇 토큰을 붙여 넣고, 안내가 나오면 봇에 `/start`를 보냅니다.
나머지는 설치 도구가 합니다.

- `~/.config/grok-telegram-bridge/token.json`(본인 계정만 읽기)과 `bridge.env`를 씁니다. 기존 `bridge.env`는 먼저 백업하고, 다른 설정은 그대로 둡니다.
- 아래 표의 스위치를 켭니다.
- tmux 세션 `grok`(소켓 `grok`)에서 Grok을 실행합니다.
- 상시 서비스(macOS launchd, 리눅스 `systemd --user`)를 설치합니다. 다시 로그인하면 브릿지가 다시 뜹니다.
- `grok-tg` 명령을 추가합니다.
- 시험 메시지를 보내고 두 방향을 한 번씩 확인합니다. 폰에서 보낸 글이 터미널의 Grok에 들어가 답이 돌아오는지(60초), 설치 도구가 Grok 세션에 친 짧은 질문이 폰에 오는지(90초) 봅니다. 결과는 터미널과 채팅에 함께 남습니다. 확인마다 짧은 Grok 턴을 하나씩 씁니다.

| 스위치 | 켜지는 것 |
| --- | --- |
| `GRB_CHAT_LANE=tui` | 메시지마다 숨은 `grok -p`를 돌리지 않고, 보이는 tmux 세션의 Grok에 입력합니다 |
| `GRB_TUI_MIRROR_LOCAL=1` | 그 세션에서 직접 친 질문도 진행 카드·중지 버튼·답변과 함께 폰에 옵니다 |
| `GRB_TUI_FALLBACK_HEADLESS=0` | 세션이 사라지면 숨은 프로세스로 대신 답하지 않고 알립니다 |
| `GRB_STOP_BUTTON=1`, `GRB_SEND_NOW_BUTTON=1`, `GRB_QUESTION_PIN=1` | 중지·즉시입력 버튼과 `/model` 카드 고정을 유지합니다 |

그다음부터는 어느 터미널에서든 `grok-tg`를 치면 폰이 쓰는 그 Grok 세션에 붙습니다. 세션이 없으면 먼저 띄웁니다.
`Ctrl+B` 다음 `D`를 누르면 빠져나옵니다. Grok은 계속 돕니다.
다른 터미널에서 따로 띄운 Grok은 폰과 연결되지 않습니다. 설치 도구가 그런 Grok을 보면 경고합니다.
`n`으로 답하면 공개 기본값(헤드리스 레인, 미러 없음)을 유지합니다. `--like-author`는 질문을 건너뜁니다.
`--dry-run`은 할 일만 보여 주고 아무것도 쓰거나 띄우거나 보내지 않습니다.

## 언어와 기본 사용

봇 대화에서 다음 명령을 보냅니다.

```text
/language ko
/language en
/language
/ping
```

- `/language ko`: 브릿지 안내와 버튼을 한국어로 표시합니다.
- `/language en`: 영어로 표시합니다.
- `/language`: 현재 선택을 확인합니다.
- `/ping`: 브릿지 연결 응답을 확인합니다.

언어 명령은 브릿지가 처리하며 Grok 입력으로 보내지 않습니다. 선택은 재시작 후에도 유지됩니다.
그다음 평소처럼 요청을 보내면 연결된 Grok 세션에서 처리하고 완료된 답변을 전달합니다.
승인·선택 카드의 안내는 선택한 언어로 보이고, 질문·선택지·모델 이름·코드는 원문을 유지합니다.

## 설정과 문제 확인

처음 사용할 언어는 `.env` 또는 서비스 설정의 `GRB_LANGUAGE=ko`로 지정할 수 있습니다.
이미 대화에서 고른 언어가 있으면 그 선택을 우선합니다. 설정을 바꾸려면 `/language`를 사용하세요.
여러 브릿지를 같은 컴퓨터에서 쓰더라도 언어 선택 파일은 브릿지별로 구분됩니다.

응답이 없으면 프로세스 실행 여부, 본인 채팅 ID, 토큰 파일 경로와 연결한 터미널 세션을 확인하세요.
로그를 공유할 때는 토큰과 대화 내용을 제거하세요. 언어 파일 저장에 실패하면 오류를 알리고 기존 언어를 유지합니다.

## 지원 범위

연결·전달·오류 안내, 승인·선택 카드 설명, 복구·확인 버튼과 주요 설정 응답을 번역합니다.
AI 답변과 사용자 입력을 번역 서비스로 보내지 않으며 별도 번역 비용이 없습니다.
터미널 설치·진단 출력, 고급 운영 보고와 CLI가 직접 만든 문구는 기존 언어를 유지합니다.
자세한 검증 경로는 [언어 설정 문서](docs/i18n.md), 고급 설정은 [영문 문서](README.md)에 있습니다.
