# Grok Telegram Bridge 0.5.6

Customer re-release of the default-off suggestion change.

## What is new since 0.5.5

- Same behavior as 0.5.5: suggested-reply bubbles and confirm buttons stay
  off unless you set `GRB_SUGGESTED_REPLY_SPLIT=1` and
  `GRB_SUGGESTED_CONFIRM=1`.
- Public comments for those flags are in English.
- This tag is the installable customer drop. Clone `main` or download the
  0.5.6 source archive.

Copy-paste command bubbles and ordinary approval buttons are unchanged.
